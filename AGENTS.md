# Agent instructions

## Scope
- Keep this file static and procedural. Milestones, slices and decisions live in `planning/`.
- Merged `main` and merged PR history are the source of truth for what is done.
- Project-wide decisions (0019 top goal, 0020 package plan, 0014 open release, 0017/0018 evaluation) live in heocr-engine's `planning/decisions/` and bind this repository.

## Setup and validation
- Install: `pip install .` (Python 3.11 or later).
- Test: `python -m unittest discover -s tests -t .`
- CI runs offline fixture tests only. Tests make no network calls, download nothing and need no external program (Tesseract, LibreOffice).
- Test fixtures are synthetic and generated by code in `tests/synth/`. Never commit real documents: real government documents form a private corpus for internal evaluation only (decision 0020, item 5), and evaluation owns it.

## Branching and commits
- Start from the latest `main`. Branch as `<tool>/<topic>` (for example `claude/d1b-identify`).
- Use Conventional Commits (`type(scope): subject`).
- Credit ported code in the commit that ports it (source repository, file and function).

## Pull requests
- Open non-draft PRs with tests and an explanation of what changed, why, the impact, and the validation performed.
- Agent-authored PR bodies and comments begin with `Agent: <role>[<tool>#<host>] | Thread: <thread> @ heocr`.
- Planned work uses the notation in `planning/README.md`. The PR title is `<notation>: <sentence-case summary>`, and the body has a top-level `## Planning notation` section naming the notation, its milestone and the plan document. If no notation exists yet, define it in `planning/` first.
- Label every PR (`kind:*`, `area:*`, `roadmap:*`) and assign it to its GitHub milestone.
- Do not merge your own PR. Every PR waits for green CI and review by the lead or the maintainer (heocr-engine decision 0001). Merges are squash merges.
- Before opening a PR, fetch and check open PRs and branches; stop and ask if the work would collide.

## Hard boundaries
- **Licences (decision 0020):** the core and its default install have permissive dependencies only. Copyleft libraries (PyMuPDF, Poppler, python-bidi and the like) may come in only as optional extras that the user installs on purpose, documented as bringing their licence terms; no default route may require one.
- **External programs** (Tesseract, LibreOffice) are optional and never bundled. Without them the core still runs and records the route it could not take.
- **Models (decision 0014):** no model with non-commercial or field-of-use restricted weights in any route. No weights are committed; downloads are explicit and pinned by sha256.
- **Offline core:** the core makes no network calls.
- **No silent loss:** text that could not be read is reported as unread or flagged, never dropped quietly.
- **Repairs are not normalization:** repairs restore source characters, each by a listed rule and logged per block; with repairs off the output is the extracted text. Normalization stays outside the default output (heocr-engine decision 0002).
- **Output contract:** `heocr_document.v1` payloads never contain local filesystem paths or file names.
